Milestone 1 Specification & Architecture

1. What is Extracted & Why

  • Selector(s): Identifies precisely which DOM elements are targeted (e.g. .navbar, h1, h2, .hero).
  • Properties (Key-Value Dict): Declarations captured as a dictionary (e.g. {"color": "#333", "display": "flex"}) for immediate programmatic querying.
  • Property Count: Complexity indicator representing declaration density without requiring client iteration.

2. Edge Case Handled: URL Values with Colons

Standard naïve splits on : corrupt declarations like: background: url('https://example.com/hero.jpg'). The parser uses split(':', 1) to safely split on the first colon only, keeping web URLs completely intact.

3. Groq AI Integration

Parsed rules are structured and reviewed by the Groq LLM (openai/gpt-oss-120b) with deterministic output returning exactly:

{"summary": "...", "suggestions": [...], "accessibility": [...], "best_practices": [...]}
